# Girlsday2026

Für den Workshop am Girlsday 2026 an der TU Bergakademie Freiberg befinden sich hier jupyter Notebooks, die einige einfache AI-Modelle in Python implementieren. Die Notebooks sind so gestaltet, dass sie auch ohne tiefere Programmierkenntnisse nachvollzogen werden können.

Neu hinzugekommen ist das 05 Notebook in dem einfache LLM Modelle besprochen werden. Wir nutzen OpenAI Library mit Chat AI der Uni Göttingen mit Key in `.chatai_api_key` . (Neu erstellen auf <https://saia.gwdg.de/dashboard> )
